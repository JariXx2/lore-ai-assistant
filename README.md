# Локальный ИИ-помощник для авторов вымышленных миров

Проект предназначен для поиска сведений в текстах, описывающих вымышленный мир, и формирования ответов с указанием исходных фрагментов.

## Текущий статус

Подготовлены описания технического прототипа и первой рабочей версии. Реализация ещё не начата.
