# Технический прототип

## Цель

Данный прототип будет показывать целесообразность и возможность полной реализации данного проекта

## Входные данные

- В качестве примера будем использовать файлы формата fb2, либо техническая, либо художественная литература, чтобы ответы были более очевидны
- Объем будет определен перед эксперементом

## Сценарий работы

1. Система читает текст.
2. Подготавливает и делит его на фрагменты.
3. По вопросу находит подходящие фрагменты.
4. Локальная модель формирует ответ.
5. Система показывает фрагменты, на которых основан ответ.

## Ожидаемый результат

Так как это прототип в ответе мне интересно будет ли указаны нужные фрагменты и тексты (файлы) которые были испольованы для составления ответа, а так же корректность самого ответа. Так что в ответе должен содержаться список файлов которые были задействованы, местоположение фрагмента (глава, страница или иной маркер), а так же ответ который сделан на основе текста.

## Как проверю результат

- Проверю соответсвует ли найденый фрагмент
- Проверю соответсвие текста
- В случае отсутвия нужного ответа программа должна выдать в качестве ответа "На данный момент необходимя информация не найдена"

## Ограничения прототипа

- Веб-интерфейс не разрабатывается.
- Backend API не разрабатывается.
- Прототип не анализирует сложные связи и скрытые смыслы между текстами
