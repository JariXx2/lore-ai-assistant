# MVP локального ИИ-помощника

## Назначение

Приложение предназначено для поиска и анализа сведений в корпусе документов, описывающих вымышленный мир. Система позволяет задавать вопросы по загруженным материалам и получать ответы с указанием исходных фрагментов.

## Основной пользовательский сценарий

1. Пользователь загружает файлы форматов FB2 и TXT.
2. Система извлекает текст из документов и подготавливает его для последующего поиска сведений.
3. После анализа текстов пользователь может задать вопрос
4. На основе вопроса пользователю выдается готовая информация, а так же ссылки на источники

## Возможности пользователя

- Загрузить файлы и удалить лишние
- Задать отдельный вопрос по загруженным документам.

## Функции системы

- Подготавливает текст и разбивает на фрагменты
- Фрагменты сохраняются в форме, пригодной для поиска
- По вопросу пользователя система находит относящиеся к нему фрагменты в одном или нескольких документах
- Локальная языковая модель составляет ответ
- Пользователь получает ответ и указание фрагментов на которых он основан.
- Если нет подтверждающих сведений система пишет об этом

## Критерии готовности

- После загрузки документа пользователь задаёт вопрос, ответ на который содержится в нём. Система находит сведения и формирует ответ
- Сверь ответ и указанный фрагмент с исходным документом. Сведения в ответе должны подтверждаться фрагментом, а источник должен позволять его найти.
- Задай вопрос, ответа на который в документах нет. Система должна сообщить о недостатке сведений, а не придумывать ответ.

## Не входит в MVP

- Поддержка форматов DOC, DOCX и PDF. Их можно добавить после реализации обязательных функций.
- Уточняющие вопросы с учётом истории разговора.
- Автоматическое выявление возможных противоречий между утверждениями в загруженных документах.
